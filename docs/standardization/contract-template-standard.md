# Contract Template Standard

Contracts should reference the client, project, quotation, and selected contract template.

Template types:

- Onboarding contract
- Maintenance contract
- SOW
- NDA
- Change request
- Project closure / acceptance

Required dynamic inputs:

- Contract number and version
- Client and project
- Contract type
- Start/end dates
- Contract value
- Scope reference
- Legal terms
- Renewal terms
- Signature blocks
