# Quotation Template Standard

Quotations should be generated from project-specific data plus reusable settings.

Required dynamic inputs:

- Client and project
- Quotation title and reference number
- Project overview
- Scope of work
- Tech stack
- Pricing modules
- Discount, tax, and final total
- Payment milestones
- Valid until date
- Terms and conditions

Reusable data sources:

- `company_settings`
- `document_templates`
- `standard_terms`
- `payment_milestone_templates`
- `service_catalog`
