# Required Information Standard

Use this as the master checklist for plug-and-play operations.

## Company Master Information

- Company name and legal name
- Logo URL
- Email, phone, website, address
- GST/PAN
- Bank details
- Authorized signatory name
- Default footer text

## Client Information

- Company name
- Contact person
- Email, phone, website
- GST/PAN
- Billing address
- Shipping or project address
- Notes

## Project Information

- Project name and type
- Project overview and business objective
- Scope summary
- Start date and target completion date
- Technology stack
- Assumptions, dependencies, and out-of-scope items

## Commercial Information

- Quotation, contract, and invoice references
- Pricing items/modules
- Discounts, taxes, payment terms, and milestones
- Linked client and project

## Delivery Information

- Maintenance plan, included hours, SLA terms
- Support channels, renewal date, exclusions
- Support tickets, priorities, status, SLA hours, and time spent
